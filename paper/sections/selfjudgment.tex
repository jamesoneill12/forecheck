\section{Can the acting agent judge its own scope?}
\label{sec:selfjudgment}

A cheaper alternative to an external checker is to ask the acting agent,
inside its own system prompt, whether to proceed. We give the untrained 8B
instruct model an agent system prompt carrying the identical entitlements,
delegated scope, and policy text, then the pending call, and read one
\textsc{allow}/\textsc{stop} verdict off the first output token, scored
against all eleven labels on 2,000 \texttt{heldout\_family} rows
(Table~\ref{tab:selfjudgment}).

On the generator's entitlement-based scope labels the agent is at chance
(AUROC 0.54--0.67 on the three identity dimensions); the checker beats it on
all eleven. A single verdict scored against eleven labels is structurally
limited, so part of the gap is definitional, and the finding does not travel:
on InjecAgent (\S\ref{sec:external}) the same prompt flags every attacker
call as \textsc{stop} and scores 1.000 on that benchmark's scope label, above
the trained checker. The agent recognises an action nobody asked for; it does
not check a call against a delegated grant. The injection reversal
(0.166 to 0.507 when the preamble is removed) is measured on v4 text in which
every injected call carries the leaked ``attacker'' literals, so we report it
as confounded rather than as evidence about attention.
