\section{Can the acting agent judge its own scope?}
\label{sec:selfjudgment}

The classifier above is an external checker: it never generates the action,
only scores it. A cheaper alternative is to ask the acting agent itself,
from inside its own system prompt, whether to proceed. We give the same
untrained instruct models used as the decoder's base (2B, 8B) a Fin-style
system prompt carrying the identical entitlements, delegated scope, and
policy text, followed by the pending tool call, and read a single
ALLOW/STOP verdict off the first output token. That one scalar is scored
against all eleven dimensions' labels: tracking the external checker means
an undifferentiated act/refuse decision happens to catch that risk; lagging
badly means the dimension needs external, per-dimension structure the
agent's own judgment does not supply.

Figure~\ref{fig:self-judgment} shows the pattern holds across all eleven
dimensions, not just the five in Table~\ref{tab:selfjudgment}: the agent's
bars track the chance line closely everywhere except
\texttt{policy\_conflict} and \texttt{external\_communication}, while the
external checker clears 0.84 AUPRC or better on every dimension.

Two findings. First, \textbf{the agent cannot judge its own scope from
inside its prompt}: with full identity context the 8B agent is at or near
chance on every identity-dependent dimension (AUROC 0.53--0.67, not shown),
the same level as the zero-shot safety models in \S\ref{sec:identity}. The
delegation information sits in its own prompt and is not turned into a
decision. Second, \textbf{identity context makes the agent worse, not
better, at spotting injection}: stripping the policy and scope text raises
\texttt{prompt\_injection\_influence} AUPRC from 0.169 to 0.498 -- a long
policy preamble appears to dilute attention to an injected instruction
elsewhere in the trajectory. Both argue for keeping an external checker in
the loop rather than trusting the agent's own judgment, even on
content-style dimensions. The small identity signal that does exist
(\texttt{unauthorized\_scope} AUROC 0.61 full vs.\ 0.48 stripped) shows the
agent reads the context a little; it does not turn that into a usable
decision, and the gap to the external checker's 0.960 macro AUPRC persists
regardless.

\textbf{Row-for-row comparison on v4} (\texttt{agent-self-8b-v4/}). Scoring
the decoder 2B v4 checker against the identical 2,000 \texttt{heldout\_family}
rows used for the 8B agent above, it beats the agent's own single-verdict
score on every one of the eleven dimensions, by 0.45--0.90 AUPRC:
\texttt{unauthorized\_scope} 0.999 vs.\ 0.135, \texttt{policy\_conflict}
0.964 vs.\ 0.509, \texttt{insufficient\_context} 0.841 vs.\ 0.086,
\texttt{prompt\_injection\_influence} 0.804 vs.\ 0.166 (agent stripped:
0.507). Identity context in the agent's own prompt still costs it on
injection detection even though stripping barely moves the checker; the
agent's own macro is 0.242 full vs.\ 0.281 stripped.
