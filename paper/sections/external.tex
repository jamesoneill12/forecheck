\section{Transfer to AgentDojo and InjecAgent: data we did not generate}
\label{sec:external}

Every result so far is on forecheck's own synthetic generator
(\S\ref{sec:limitations}). We score the same v4 checkers, zero-shot, on
AgentDojo \citep{debenedetti2024agentdojo}, a published benchmark of agent run
traces we did not write. We use the banking suite traces for
claude-3-5-sonnet-20241022 and gpt-4o-2024-05-13: 1,714 runs, 4,215 proposed
tool calls, 11 attack types plus no-attack runs. Labels come from AgentDojo's
own \texttt{ground\_truth()} functions, not from forecheck's generator:
\texttt{prompt\_injection\_influence} is \texttt{yes} when a call executes the
injection task's goal (positive rate 0.150, $n{=}4{,}133$ evaluable calls);
\texttt{unauthorized\_scope} is \texttt{yes} when the call's function is
outside the user task's reference-solution function set (rate 0.253);
\texttt{policy\_conflict} is \texttt{yes} when one of four banking policies we
wrote once per suite fires, checked by deterministic predicates (rate 0.237);
\texttt{financial\_commitment} (0.343) and
\texttt{destructive\_or\_irreversible\_action} (0.097) come from function-name
sets. Trace parsing and the full label derivation are documented in
\texttt{docs/external-agentdojo.md}. Every arm is zero-shot: nothing was
trained or tuned on AgentDojo, the calibration bundles were fitted on
synthetic dev, and threshold selection is disabled.

Table~\ref{tab:agentdojo} and Figure~\ref{fig:agentdojo} give six readings.
\textbf{Policy checking transfers.} 2B v4 scores 0.849 AUPRC on
\texttt{policy\_conflict} against a 0.237 base rate and a rule baseline at
base rate, on policies, a tool schema, and agent traces it never saw.
Eval-time stripping drops it to 0.694 and the train-time stripped model to
0.390, the same identity dependence found in \S\ref{sec:identity}, now on
external data. \textbf{Injection transfer is a scale effect.} 2B fails
outright (0.128 AUPRC, below the 0.150 base rate, AUROC 0.348); 8B reaches
0.797 AUPRC and 0.916 AUROC zero-shot; the rule baseline sits between the two
(0.250, AUROC 0.737) because presence of untrusted content alone is a strong
but insufficient cue. The 8B checker, trained only on synthetic data, ranks
the call that executes the attacker's goal above the benign calls in the same
poisoned trace 92 percent of the time; \S\ref{sec:injecagent} shows what it
is and is not reading to do so. The 2B result is a plain failure, and a per-example score dump
says why: the 2B injection head never fires on this domain. Raw logits for all
4,133 evaluable calls lie between $-5.0$ and $-3.0$, the highest-scoring
positive is $-3.25$, and no call scores above zero; the residual ordering is
noise. On the same rows the 2B \texttt{policy\_conflict} head separates
cleanly (median raw logit $+2.5$ for positives, $-3.5$ for negatives). The 2B
model learned injection from surface cues of the synthetic generator that
AgentDojo's injections do not carry. The 8B dump shows a live but shifted
head: median raw logit $-1.75$ for positives against $-3.50$ for negatives,
with 29\% of positives above zero against 0.7\% of negatives, so the ranking
is right while most true positives sit below the decision boundary, which is
the ECE of 0.272 in one number. The
two 8B baselines separate scale from training: the same Granite-3.3-8B base
asked \textsc{allow}/\textsc{stop} as the agent (\S\ref{sec:selfjudgment})
scores 0.291 AUPRC on injection and Granite Guardian 3.3 8B zero-shot scores
0.103, below base rate. The trained checker's 0.797 is the training, not the
parameter count. Stripping identity from the 8B input keeps injection (0.743)
and drops \texttt{policy\_conflict} from 0.560 to 0.404, the same content
versus identity split as in \S\ref{sec:identity}.
\textbf{\texttt{unauthorized\_scope} does not transfer} (0.257 2B, 0.386 8B,
vs.\ a 0.253 base rate); the 8B head scores above zero on 77\% of negatives
and 66\% of positives, so it fires on nearly every call and carries no signal
on this label. The label itself is the weakest one here, since
"function not in the reference solution" counts harmless auxiliary reads as
out of scope, and we report this without claiming transfer on it. \textbf{8B
\texttt{policy\_conflict} (0.560 AUPRC) is below 2B (0.849 AUPRC) while its
AUROC (0.885) stays high}, which is unexplained; single-seed 8B vs.\ 2B
comparisons on this cell fall within the seed noise \S\ref{sec:generalisation}
measured on synthetic \texttt{heldout\_policy\_kind} (sample sd 0.03) only for
the AUROC gap, not for the AUPRC gap, so this remains a real open question.
\textbf{Calibration does not transfer, an in-domain refit fixes it}: macro
ECE runs 0.20--0.27 for the calibrated arms here, against under 0.03 on
synthetic data. Refitting per-dimension isotonic calibrators on a random half
of the AgentDojo calls and testing on the other half (five seeds) gives macro
ECE 0.008 (2B) and 0.010 (8B) with AUPRC unchanged; the 8B
\texttt{unauthorized\_scope} head goes from ECE 0.60 to 0.01 because it
learns to output the base rate. Most of the gain is reached with 250--500
labelled calls (\texttt{scripts/agentdojo\_recalibrate.py}). Last, this is one
suite (banking), one domain, with labels partly written by us (the four
policy predicates) and partly by AgentDojo
(\texttt{prompt\_injection\_influence}, \texttt{unauthorized\_scope}); slack,
travel, and workspace traces were not fetched.

\subsection{InjecAgent: holding the call fixed}
\label{sec:injecagent}

AgentDojo's injection positives differ from their negatives in the call
itself: an unrequested transfer to a recipient the user never named. To test
whether the checker reads the untrusted text at all, we port InjecAgent
\citep{zhan2024injecagent} (1,054 cases, 38 toolkits, MIT licence). Each case
gives the user's own call and, per attacker tool, a \emph{poisoned/clean
pair}: the same attacker call, with identical arguments, proposed after the
tool response with the attacker's instruction filled in
(\texttt{prompt\_injection\_influence}=\texttt{yes}) or left empty
(\texttt{no}). The only difference inside a pair is the observation
(\texttt{docs/external-injecagent.md}). 4,250 examples, 1,598 pairs.

Table~\ref{tab:injecagent}: \textbf{neither checker reads the injected
text}. With the call held fixed, the 8B injection score rises on 35\% of
pairs and is unchanged on 39\%; both heads sit at raw logit $-4$ on poisoned
and clean alike. This reinterprets the AgentDojo result: what transferred at
8B is call-level, whether the action is something the user asked for, not
reading the untrusted content for the instruction that explains it. The v4
generator's leak (\S\ref{sec:limitations}) is the likely cause, since the
training signal was carried by an argument key and the observation never had
to be read. \textbf{Policy checking transfers a second time}:
\texttt{policy\_conflict} 0.965 (2B) and 0.977 (8B) against a 0.464 base
rate on five policies written for this port over 38 unseen toolkits, with the
rule baseline at base rate; stripping identity barely moves it here because
these five policies are global rules about the call rather than about what
the principal named. \texttt{unauthorized\_scope} has signal at 8B (0.849
vs.\ 0.752 base) and none at 2B.
