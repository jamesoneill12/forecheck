\section{Transfer to data we did not generate}
\label{sec:external}

We score the checkers zero-shot on two published benchmarks. Nothing was
trained or tuned on either; calibration was fitted on synthetic data and
threshold selection is disabled. The leak-free v6 checkers are the paper's
models; v4 rows are the pre-fix comparison.

\textbf{AgentDojo} \citep{debenedetti2024agentdojo}: banking-suite traces
for two frontier agents, 1,714 runs, 4,215 proposed calls, 11 attack types
plus no-attack runs. Labels come from AgentDojo's own \texttt{ground\_truth()}
functions: \texttt{prompt\_injection\_influence} is \texttt{yes} when a call
executes the injection task's goal (positive rate 0.150);
\texttt{unauthorized\_scope} when the call's function is outside the user
task's reference solution (0.253). \texttt{policy\_conflict} (0.237) is
\emph{ours}: four banking policies, each a deterministic predicate over
user-named recipients. \textbf{InjecAgent} \citep{zhan2024injecagent}: 1,054
cases over 38 toolkits. AgentDojo's injection positives differ from negatives
in the call itself, so it cannot tell whether a checker reads the untrusted
text or the call. InjecAgent can: for each attacker tool we build a
\emph{poisoned/clean pair}, the same attacker call with identical arguments,
proposed after the tool response with the attacker's instruction filled in
(\texttt{yes}) or removed (\texttt{no}). 4,250 examples, 1,598 pairs;
\texttt{policy\_conflict} from five generic policies about the call's shape.

\textbf{Policy checking transfers, and on AgentDojo it stays
identity-dependent.} On banking \texttt{policy\_conflict}, whose predicates
reference recipients the user named, 2B v4 scores 0.849 against a 0.237 base
rate on policies, a tool schema, and traces it never saw; eval-time stripping
drops it to 0.694 and the train-stripped model to 0.390. The v6 checkers
score lower here (0.670, 0.785) with the same stripping pattern (0.521,
0.450). This is the one external result that bears on the identity thesis.
On InjecAgent the same dimension scores 0.92--0.98 and stripping barely moves
it: the five policies are rules about the call's shape, so it is a content
result.

\textbf{Injection before the fix: the v4 heads barely read the untrusted
text.} 2B v4 is below base rate on AgentDojo injection (0.128, AUROC 0.348):
its injection head never fires on this domain (raw logits for all 4,133 calls
in $[-5,-3]$) while its policy head separates the same rows; 8B v4 reaches
0.701. On InjecAgent, with the call held fixed, both v4 heads
sit near raw logit $-4$ on poisoned and clean alike and return an identical
score on 24\% (2B) and 39\% (8B) of pairs (Figure~\ref{fig:injecagent-margins}). Counting ties as half, they rank
the poisoned variant higher on 0.624 and 0.546 of pairs, significantly above
0.5 (sign test on decided pairs, $p<10^{-5}$) but small. Whether the 8B
AgentDojo transfer was call-level reading or a head that only fires on long
observations is undetermined; a payload-deletion counterfactual with the call
held fixed would decide it and has not been run.

\textbf{The cause was a label leak in our generator.} Contrasting rendered
calls between injected and non-injected synthetic examples showed that the
v1--v5 generator wrote an \texttt{instructed\_target} argument into every
injected call and no other (presence 1.00 vs.\ 0.00 over 13,312 v4 rows) and
drew its value from five literals, three containing ``attacker''
(Appendix~\ref{sec:appendix-leak}). The synthetic metric could not show this.
A quarter of synthetic injection positives come from a compromised tool
schema and render no injected text at all, so a detector that reads only the
observation and a detector that reads only the leaked key are both capped
near 0.75--0.80 AUPRC; the checker's 0.80 is consistent with either. The
synthetic score measured the ceiling, not what the head read.

\textbf{v6 restores transfer; the fix is a bundle.} v6 removes the key,
fills the target argument for benign calls too, and lengthens and randomises
observations. Retrained on v6 with identical size and recipe, 2B reaches
0.693 on AgentDojo injection (AUROC 0.928) and 8B 0.838 (0.966), and both
heads fire (2B v6 median raw logit $+4.5$ for positives vs.\ $-3.0$). On
InjecAgent both rank the poisoned variant strictly above its clean twin on
0.977 of pairs with under 2\% ties; the synthetic injection score did not
change (0.804 to 0.787 on \texttt{heldout\_family}). Observation length
alone could also explain the AgentDojo gain, since AgentDojo's records are
about 2,000 characters against v4's 132-character templates; the two changes
were not separated and we claim only that the bundle is sufficient.

\textbf{Two confounds in the pair test, one ruled out.} The clean twin is
the poisoned observation with the instruction deleted, so it is shorter in
all 1,598 pairs; a ``longer observation wins'' detector scores 1.000, above
the checkers. A length-matched clean control has not been run. Second, the
port marks the destination's trust from whether its identifier appears in
the observation, which flips inside 39\% of pairs and is not removed by
stripping. On the 972 pairs where destination trust is equal in both
members, the v6 checkers win 0.963--0.972, so this confound does not carry
the result. The length confound remains open.

\textbf{What does not transfer.} \texttt{unauthorized\_scope} is near base
rate on AgentDojo for every checker (0.21--0.36 vs.\ 0.253); the label counts
harmless auxiliary reads as out of scope. On InjecAgent, 8B v6 is below base
rate (0.677 vs.\ 0.752) until the port's placeholder principal and scope
fields are removed (0.917). Removing identity \emph{helps} on several
external cells, which fits the thesis only in its narrow form: the right
fields help, generic ones hurt. Calibration does not transfer (macro ECE
0.20--0.27 on AgentDojo vs.\ under 0.03 synthetic); isotonic refitting on
250--500 labelled calls restores ECE 0.01 with AUPRC unchanged. Over all
four AgentDojo suites (30,143 calls), 8B v4 injection holds on three and is
weak on travel; 2B v4 is at base rate everywhere; v6 has not been run on that
export (Appendix~\ref{sec:appendix-external}).
