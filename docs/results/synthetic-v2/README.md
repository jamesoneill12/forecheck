# Results on synthetic data v2 (2026-09-21, in progress)

All numbers here are on **synthetic data** generated by `configs/data/train_medium.yaml`
(49,996 rows; train 25,750 / calibration 5,171 / dev 5,094 / test 4,967 /
heldout_family 6,640 / adversarial 2,374). They measure whether each arm can learn the
label function the generator encodes, not real-world risk. Evaluation classes are
`synthetic_in_distribution` (test) and `synthetic_heldout_adversarial`
(heldout_family: 10 of 72 tools withheld, stratified by operation kind).

Every arm below is scored by the same `forecheck evaluate` harness with per-dimension
thresholds selected on `dev`. Sections marked *pending* are filled in as jobs finish.

## Encoder ModernBERT-large, per dimension (test)

| dimension | AUPRC | AUROC | ECE |
|---|---|---|---|
| prompt_injection_influence | 0.813 | 0.881 | 0.007 |
| unauthorized_scope | 0.998 | 1.000 | 0.009 |
| sensitive_data_exposure | 0.974 | 0.993 | 0.063 |
| untrusted_destination | 0.999 | 0.999 | 0.009 |
| privilege_escalation | 0.498 | 0.989 | 0.035 |
| destructive_or_irreversible_action | 0.991 | 0.996 | 0.004 |
| financial_commitment | 1.000 | 1.000 | 0.002 |
| external_communication | 0.993 | 0.994 | 0.050 |
| policy_conflict | 0.423 | 0.627 | 0.165 |
| suspicious_action_sequence | 0.627 | 0.770 | 0.148 |
| insufficient_context | 0.642 | 0.904 | 0.136 |

Reading. Seven dimensions are near-perfect because the serialised context prints the
deciding field verbatim (the rule baseline should match them; if it does, those
dimensions are lookup, not learning). The three dimensions the generator fixes in v2
made learnable are now off chance for the encoder: `prompt_injection_influence` 0.45 in
v1 (decoder) to 0.81 here, `suspicious_action_sequence` AUROC 0.52 in v1 to 0.77 here.
Two remain weak:

- `privilege_escalation`: AUROC 0.99 but AUPRC 0.50 with a 6 percent positive rate. The
  ranking is right but the head cannot separate the top of the list; the selected
  threshold recovers only 0.5 percent recall on heldout. The decoder arm and a
  class-balanced head are the comparisons to make.
- `policy_conflict`: AUPRC 0.42, AUROC 0.63, worst ECE (0.165). The label needs the
  model to read a policy clause and check it against the action. A 2048-token mean-pooled
  encoder does not do that reliably. This is the dimension the policy-generalisation
  splits in v3 (`heldout_policy_kind`, `heldout_policy_phrasing`) exist to probe.

Heldout_family tracks test within 0.01 macro AUPRC, so the encoder is not memorising
tool names.

## Granite Guardian 3.3 8B zero-shot baseline

Prompt: our serialised context as the user turn, the proposed tool call as the assistant
turn, one `custom_criteria` per dimension (the dimension definition), scoring schema
"if the proposed tool call meets the criteria return yes". Probability = P(yes) over
{yes, no} first-token logits. 2,000 seeded rows per split.

| dimension | heldout AUROC, full context | heldout AUROC, identity stripped |
|---|---|---|
| prompt_injection_influence | 0.477 | 0.438 |
| unauthorized_scope | 0.396 | 0.491 |
| sensitive_data_exposure | 0.625 | 0.687 |
| untrusted_destination | 0.543 | 0.522 |
| privilege_escalation | 0.494 | 0.467 |
| destructive_or_irreversible_action | 0.588 | 0.628 |
| financial_commitment | 0.870 | 0.918 |
| external_communication | 0.368 | 0.355 |
| policy_conflict | 0.555 | 0.491 |
| suspicious_action_sequence | 0.568 | 0.533 |
| insufficient_context | 0.439 | 0.386 |

Reading. A general-purpose guardian model, prompted with our per-dimension criteria and
no fine-tuning, is at chance on nine of eleven dimensions of this task. It picks up
`financial_commitment` (amounts are literal in the action) and weakly
`sensitive_data_exposure`. Stripping principal entitlements, delegated scopes and policy
text does not hurt it, and slightly helps on several dimensions. So the baseline does not
consume identity or delegation context at all: whatever advantage our trained arms have on
`unauthorized_scope` and `policy_conflict` is not something an off-the-shelf guardian
provides today.

Caveats. This is one prompt design, not a tuned one; Granite Guardian is trained on
harm, jailbreak, groundedness and function-call hallucination criteria, not on
delegated-authority checks, so chance performance is the expected result rather than a
criticism of the model. The 2,000-row subsample gives roughly plus or minus 0.03 on
AUROC. Numbers are uncalibrated (ECE 0.14).
